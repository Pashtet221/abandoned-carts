# Gelikon Abandoned Carts

Плагин отслеживает корзины WooCommerce. Поддерживает классическое оформление заказа и блочный checkout (Store API).

## Статусы

- **Активные** — корзины, для которых заказ ещё не оформлен.
- **Брошенные** — активные корзины после тайм-аута; также корзины отменённых заказов и заказов с неудачной оплатой.
- **Ожидают оплаты** — оформленные заказы со статусами `pending` или `on-hold`.
- **Завершённые** — оплаченные заказы (`processing`/`completed`). Возврат средств не превращает покупку в брошенную корзину.

Заказ хранит ID корзины в метаданных `_gl_ac_cart_id` через WooCommerce CRUD API (совместимо с HPOS). Поэтому уведомление об оплате может обновить корзину без браузерной сессии покупателя. Поздний AJAX-запрос или очистка корзины не перезаписывает запись оформленного заказа. Добавление нового товара после оформления начинает отдельную запись, сохраняя предыдущую покупку.

При входе гостя в аккаунт используется ID корзины, сохранённый в сессии WooCommerce. Если сессия полностью утрачена или покупатель пришёл с другого устройства, автоматическое сопоставление независимых корзин по email не выполняется.

После обновления плановое событие `gl_ac_mark_abandoned` сверяет старые записи, у которых уже сохранён `completed_order_id`, с текущими заказами: до 100 записей за запуск. Событие запускается через WP-Cron ежечасно, при наличии запросов к сайту либо внешнего запуска cron. Старые записи без связи с заказом автоматически исправить достоверно невозможно.

## Проверка

Интеграционный тест запускается через WP-CLI **только на отдельном тестовом WordPress с активными WooCommerce и этим плагином**:

```sh
wp eval-file wp-content/plugins/gelikon-abandoned-carts/tests/order-lifecycle.php
```

Тест создаёт и удаляет тестового покупателя, товар, заказы и корзины. Проверяет оформление, оплату без сессии, смену сессии при входе, поздние запросы, новую покупку, блочный checkout, повторную оплату и исправление старой связанной записи. Плановая сверка также может обновить существующие записи тестовой базы.
